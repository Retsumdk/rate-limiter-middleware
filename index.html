rate-limiter-middleware — live token-bucket demo

A browser-side simulation of the exact algorithm in src/tokenBucket.ts and the in-memory backend. Tokens refill lazily from elapsed time (no timers), every request spends a configurable weight, and a request that cannot pay its weight is denied with the Retry-After the middleware would send.

This page simulates the algorithm in the published package; it does not call a server, and it keeps no state beyond the tab you have open.
